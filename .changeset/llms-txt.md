The package now includes `llms.txt`, a short reference for coding agents, at `node_modules/@dschz/solid-ag-grid/llms.txt` and in the JSR package. It covers installation and exact version pins, reactive props versus config objects, custom Solid components and their hooks, async data, `rowStore`, SSR, and API names that look plausible but don't exist in this package (for example `AgGridReact`, or `AgGridSolid` imported from the old `solid-ag-grid` package).
